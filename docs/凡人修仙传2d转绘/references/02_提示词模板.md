# 提示词模板

## GPT Image 2 故事板提示词

使用内置 imagegen/gpt-image-2。输入图明确标注角色：

- Image 1：当前片段原视频关键帧内容网格，只负责镜头内容和构图；
- Image 2：用户确认锁定的风格锚点，只负责风格和色彩脚本。

```text
Use case: illustration-story
Asset type: production storyboard sheet for a continuous original xianxia 2D animation
Primary request: Transform Image 1 into one coherent multi-panel storyboard sheet. Preserve the exact shot order, character identities, spatial relationships, gestures, gaze direction, camera scale, major props, and action beats from the source-content grid. Use Image 2 only as the canonical visual style anchor defined by the user's locked style specification.
Input images: Image 1 = source-content frame grid; Image 2 = user-approved locked style anchor
Scene/backdrop: original xianxia world, simplified into broad graphic masses and incomplete planes
Subject: original adult characters from the supplied content, with stable face, hair, costume silhouette, props, and screen direction
Style/medium: [STYLE_LOCK_MEDIUM_AND_LINE_LANGUAGE]
Composition/framing: exactly [SHOT_COUNT] clearly separated widescreen panels in chronological order; one dominant visual event per panel; readable silhouettes and negative space
Lighting/mood: [STYLE_LOCK_LIGHTING_AND_VALUE_RANGE]
Color palette: [STYLE_LOCK_PALETTE]
Materials/textures: [STYLE_LOCK_MATERIALS_AND_TEXTURES]
Text (verbatim): none
Constraints: no Chinese characters, no English sentences, no subtitles, no speech bubbles, no labels, no watermark, no logo, no copied film characters or frames; preserve shot order and action; keep the image suitable as a single H3 visual reference
Avoid: [STYLE_LOCK_NEGATIVE_CONSTRAINTS], invented narrative, malformed anatomy, accidental text, subtitles, watermark, logo, and storyboard layout in the final video

SHOT PLAN
[Shot 1] [time] [composition, subject, action, camera, key props]
[Shot 2] [time] [composition, subject, action, camera, key props]
...
```

如果需要给人查看台词，另做一个带准确台词版：从 `Merge-NNN.txt` 逐字复制，在画面下方单独增加台词索引区域；不要把它作为 H3 reference image。

## H3 Ref2VA 模板

写作时保持以下六段的顺序和标签，不要混入原视频参考：

```text
subject_definitions:
<Picture 1> is the single storyboard reference for this segment. It defines the exact shot order, compositions, camera scales, character placement, gestures, props, and the user's locked visual language.
<Subject 1> is the original adult cast, costumes, props, environments, and the whole-video 2D language shown in <Picture 1>. Preserve identity and spatial relationships.

summary:
[reference generation] Generate one continuous original sequence for [SEGMENT] matching the complete source duration of [DURATION] seconds. Preserve all [SHOT_COUNT] shots and their timing. Animate the storyboard as a continuous video, not a slideshow.

retention_analysis:
<Picture 1> (shot order, compositions, placement, gestures, props, locked visual rhythm): fully_preserved.
<Subject 1> (original characters and locked 2D language): fully_preserved.
Storyboard panel borders, numbers, labels and layout: removed from the final video.

detailed_description:
ABSOLUTE VISUAL RULE: render zero written characters. Dialogue is audio timing guidance only; never draw subtitles, captions, Chinese characters, speech bubbles, labels, watermark or logo. Apply [STYLE_LOCK_VISUAL_LANGUAGE] exactly. Keep the chosen value range and contrast intentional, preserve readability, and avoid accidental clipping, dense unwanted detail, photorealism or glossy CGI. Hold a readable final frame without an accidental fade to black.
[Shot 1] From [START] to [END], [concrete composition, subjects, action, camera motion, environment, light and transition].
[Shot 2] From [START] to [END], ...
...

overall_soundscape:
Use only as timing and performance guidance. The generated H3 sound will be discarded and replaced with the original source audio. [SOURCE SOUND DESCRIPTION]

non_diegetic_music:
Use only as timing and performance guidance. [SOURCE MUSIC DESCRIPTION]
```

对白、画外音和内心独白只写进 H3 prompt 用于节奏：

```text
<d>spoken dialogue timing only; never render text</d>
off-screen voiceover; the visible characters do not speak on camera
inner voiceover; no mouth movement is required
```

对于必须保留的准确台词，把中文逐字放进 `<d>`，同时在全局规则中再次声明“never render text”。
